Predictive Delivery & Analytics
Static GitHub Pages dashboard for predictive delivery analytics, route risk monitoring, and scenario forecasting.

Deploy on GitHub Pages
Create a GitHub repository.
Add index.html, styles.css, and app.js from this folder to the repository root.
In GitHub, open Settings → Pages.
Set Source to deploy from your main branch root.
Save and open the published Pages URL.
No build step or package install is required.
